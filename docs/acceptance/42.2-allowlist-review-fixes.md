## Находки приёмки (частота × вред → решение)

- **Тестировщик:** доставка пишет `blocked_chats.reason` полным текстом ошибки
  (`sendMessage: HTTP 403 — Forbidden: private chat is not in allowlist`), а не
  голым `allowlistDenied`; точное равенство не снимало бы такую пометку при
  возврате id в список (частота 2 × вред 4 = 8) → **починено**: снятие ищет
  `reason = allowlistDenied OR reason LIKE '%' || allowlistDenied`, настоящие
  блокировки Telegram не трогаются.
- **Критик:** выжившая мутация «удалять любые blocked_chats для id из списка»
  (нет теста «настоящая блокировка у id, который снова в списке»; частота 2 ×
  вред 4 = 8) → **починено**: в тестах настоящая блокировка теперь принадлежит
  id из allowlist; повторная мутация краснеет.
- Флак `TestMainLoop` (зависимость от времени суток) в изолированном прогоне
  проходит; к диффу 42.2 не относится, уже в бэклоге.
