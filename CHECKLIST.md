Параллелизуем с: этапом 3 (схема памяти не зависит от раннера).

- [x] 1.1 Singleton через PostgreSQL advisory lock; выход при занятом замке

- [ ] 1.3 Транзакционная обёртка; применение списка дельт «всё или ничего»
- [ ] 1.4 Один когнитивный worker с приоритетами (прямое обращение → группа → намерение → исследование → консолидация)
